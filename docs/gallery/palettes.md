# Palette gallery

Every color of every palette. Hover over a swatch to see its hex code. The
outlined swatch is the palette's default shade, returned by e.g. `p.red()`.
Any shade between 0 and 100 can be used, not only the ones shown here.

## IBM

`Palette("ibm")` - IBM Design Language, the default palette.

```{palette-swatches} ibm
```
